# ERP Line — سامانه مدیریت سفارش لاینر لایت

سامانه ثبت، محاسبه و مدیریت سفارش محصولات نور خطی لاینر لایت با رابط کاربری فارسی و راست‌چین.

## قابلیت‌ها

### ثبت سفارش مشتری

- فرم ثبت سفارش چندمحصولی
- انتخاب مدل پروفیل، رنگ بدنه و دمای نور
- تعیین تعداد، طول سیم خروجی و طول فیزیکی پروفیل
- افزودن و حذف ردیف‌های سفارش
- ثبت نام پروژه و شماره موبایل مشتری
- نمایش پیش‌نمایش سفارش قبل از ثبت نهایی
- تولید رسید ثبت سفارش و کد پیگیری

### محاسبه خودکار قیمت

- محاسبه قیمت بر اساس طول پروفیل و تعداد قطعات
- اعمال حداقل متراژ برای قطعات خرد
- محاسبه هزینه سیم خروجی بیشتر از مقدار رایگان
- اعمال تخفیف پلکانی بر اساس متراژ کل سفارش
- نمایش مبلغ پایه، مبلغ تخفیف و مبلغ نهایی
- نمایش جدول قیمت‌ها و تخفیف‌های پلکانی

### پیگیری سفارش

- جست‌وجوی سفارش با کد پیگیری و شماره موبایل
- نمایش مبلغ، تعداد قطعات و وضعیت سفارش
- نمایش مراحل سفارش در قالب Timeline
- نمایش زمان تقریبی تحویل در صورت ثبت آن

### مدیریت و عملیات داخلی

- API جداگانه برای عملیات مدیریتی
- ورود مدیر و مدیریت نشست کاربری
- تغییر وضعیت سفارش‌ها از طریق API
- مدیریت محصولات و قوانین BOM
- مدیریت موجودی انبار و حداقل موجودی
- پیشنهاد خرید اقلام کم‌موجودی
- ثبت گزارش عملیات سیستم
- محاسبه BOM و هزینه ساخت
- پشتیبانی از ثبت پرتی و استفاده مجدد از قطعات باقی‌مانده
- تولید اسناد چاپی شامل پیش‌فاکتور، فاکتور، برگه کارگاه، برچسب و چک‌لیست QC
- استایل پایه برای پنل مدیریت در `assets/css/pages/admin.css`

## اجرای محلی

برای اجرای صفحات PHP و اتصال به SQLite، پروژه را با وب‌سرور PHP اجرا کنید؛ باز کردن مستقیم فایل‌ها از طریق `file://` توصیه نمی‌شود.

```bash
php -S localhost:8000
```

سپس آدرس‌های زیر را در مرورگر باز کنید:

- [صفحه اصلی](http://localhost:8000/index.html)
- [ثبت سفارش](http://localhost:8000/sefaresh.html)
- [لیست قیمت](http://localhost:8000/price.html)
- [پیگیری سفارش](http://localhost:8000/track.php)

در اولین اجرای PHP، فایل `database.sqlite` در ریشه پروژه ایجاد و جداول موردنیاز توسط `Engine.php` ساخته می‌شوند.

## پیش‌نیازها

- PHP 8.0 یا بالاتر
- فعال بودن افزونه `pdo_sqlite` یا `sqlite3`
- دسترسی نوشتن PHP در ریشه پروژه برای ایجاد و به‌روزرسانی `database.sqlite`

برای بررسی افزونه SQLite می‌توانید اجرا کنید:

```bash
php -m | grep -i sqlite
```

## جریان ثبت سفارش

1. مشتری وارد صفحه ثبت سفارش می‌شود.
2. محصولات و مشخصات هر ردیف را انتخاب می‌کند.
3. مبلغ هر ردیف و مبلغ کل به‌صورت خودکار محاسبه می‌شود.
4. مشتری پیش‌نمایش سفارش را بررسی می‌کند.
5. سفارش از طریق `save-order.php` ثبت می‌شود.
6. سفارش در SQLite ذخیره شده و برای مشتری کد پیگیری تولید می‌شود.
7. مشتری می‌تواند با کد پیگیری و شماره موبایل وضعیت سفارش را مشاهده کند.

## تنظیمات قیمت و محصولات

اطلاعات پایه قیمت‌گذاری فعلی در فایل زیر قرار دارد:

```text
assets/js/config.js
```

این فایل شامل موارد زیر است:

- قیمت محصولات
- مدل‌های محصول
- رنگ‌های مجاز
- دماهای نور
- مقدار سیم رایگان
- هزینه سیم اضافه
- حداقل طول محاسباتی قطعات خرد
- پله‌های تخفیف

توابع عمومی فرانت‌اند در فایل زیر قرار دارند:

```text
assets/js/utils.js
```

## API مدیریتی

روتر API در مسیر زیر قرار دارد:

```text
api/api.php
```

Actionهای فعلی شامل موارد زیر هستند:

- `login`
- `logout`
- `get_admin_data`
- `update_order_status`
- `adjust_wallet`
- `update_inventory`
- `save_bom_and_queue`
- `save_products`
- `print`

عملیات مدیریتی نیازمند نشست مدیر هستند. قبل از استفاده در محیط واقعی، رمز پیش‌فرض مدیر در `api/api.php` را تغییر دهید و احراز هویت را ایمن‌سازی کنید.

## لایه‌های برنامه

- `engine/Engine.php`: اتصال SQLite و عملیات CRUD
- `engine/OrderService.php`: منطق سفارش، قیمت تمام‌شده، BOM، انبار و صف تولید
- `api/api.php`: مسیریابی درخواست‌های API و کنترل دسترسی
- `save-order.php`: دریافت و ثبت سفارش مشتری و نمایش رسید
- `track.php`: پیگیری عمومی سفارش توسط مشتری

## وضعیت پروژه

این پروژه در حال توسعه است. پیش از استفاده در محیط عملیاتی، موارد زیر پیشنهاد می‌شود:

- تغییر رمز پیش‌فرض مدیر
- افزودن CSRF Protection برای فرم‌ها و API
- اعتبارسنجی و محدودسازی درخواست‌های عمومی
- Escape کردن کامل داده‌های خروجی در اسناد چاپی
- فعال‌سازی HTTPS
- پشتیبان‌گیری منظم از `database.sqlite`
- افزودن تست‌های خودکار برای محاسبه قیمت و BOM
